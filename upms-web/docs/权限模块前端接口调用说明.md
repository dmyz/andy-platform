# 权限模块前端接口调用说明

## 统一响应

所有接口统一返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

分页接口的 `data` 结构：

```json
{
  "list": [],
  "total": 0,
  "pageNum": 1,
  "pageSize": 10
}
```

## 字段来源总览

| 前端字段 | 来源 | 保存时是否提交 | 说明 |
| --- | --- | --- | --- |
| `moduleCode` | `iam_permission_module.module_code` | 是 | 权限模块编码，权限定义保存时提交 |
| `moduleName` | `iam_permission_module.module_name` | 否 | 权限模块展示名，由后端返回 |
| `permissionCode` / `code` | `iam_permission.permission_code` | 是 | 权限唯一编码 |
| `permissionName` / `name` | `iam_permission.permission_name` | 是 | 权限名称 |
| `type` | `iam_permission.permission_type` | 是 | 权限类型，前端可用固定选项 |
| `resourceType` | `iam_permission.resource_type` | 是 | 资源类型，前端可用固定选项或业务页面配置 |
| `actionCode` | `iam_permission.action_code` | 是 | 动作编码，前端可用固定选项 |
| `status` | 目录表或权限表的 `status` | 是 | 数值状态，`1` 启用，`0` 停用 |
| `permissionCodes` | `iam_permission.permission_code` | 是 | 角色授权、导航授权提交的权限编码列表 |

## 权限模块目录接口

### 查询模块选项

`GET /admin/permission-module/options`

用途：

- 权限定义表单中的“所属模块”下拉。
- 角色授权、导航授权页面需要把模块编码显示为中文名称时，也可以用该接口建立映射。

返回示例：

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "label": "用户管理",
      "value": "user",
      "sortOrder": 20
    }
  ]
}
```

字段说明：

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `label` | `iam_permission_module.module_name` | 前端展示文本 |
| `value` | `iam_permission_module.module_code` | 保存权限定义时提交为 `moduleCode` |
| `sortOrder` | `iam_permission_module.sort_order` | 前端排序 |

### 分页查询模块

`GET /admin/permission-module/page`

查询参数：

| 参数 | 来源/用途 | 必填 |
| --- | --- | --- |
| `name` | 按 `module_name` 模糊查询 | 否 |
| `code` | 按 `module_code` 模糊查询 | 否 |
| `status` | `1` 启用，`0` 停用 | 否 |
| `pageNum` | 页码 | 否 |
| `pageSize` | 每页条数 | 否 |

列表项字段：

| 字段 | 来源 |
| --- | --- |
| `id` | `iam_permission_module.id` |
| `name` | `iam_permission_module.module_name` |
| `code` | `iam_permission_module.module_code` |
| `parentCode` | `iam_permission_module.parent_code` |
| `sortOrder` | `iam_permission_module.sort_order` |
| `status` | `iam_permission_module.status` 转换为数值 |
| `remark` | `iam_permission_module.remark` |
| `updateTime` | `iam_permission_module.updated_at` |

### 创建或更新模块

`POST /admin/permission-module`

`PUT /admin/permission-module/{id}`

请求字段：

```json
{
  "name": "用户管理",
  "code": "user",
  "parentCode": "system",
  "sortOrder": 20,
  "status": 1,
  "remark": "用户权限分组"
}
```

字段说明：

| 字段 | 保存到 | 说明 |
| --- | --- | --- |
| `name` | `module_name` | 模块名称 |
| `code` | `module_code` | 模块编码，唯一 |
| `parentCode` | `parent_code` | 父模块编码，可空 |
| `sortOrder` | `sort_order` | 排序号 |
| `status` | `status` | `1` 保存为 `ACTIVE`，`0` 保存为 `INACTIVE` |
| `remark` | `remark` | 备注 |

### 删除模块

`DELETE /admin/permission-module/{id}`

删除规则：

- 如果存在未删除子模块，不允许删除。
- 如果存在未删除权限定义引用该 `moduleCode`，不允许删除。
- 允许删除时执行逻辑删除。

## 权限定义接口

### 分页查询权限

`GET /admin/permission/page`

现有查询参数：

| 参数 | 来源/用途 | 必填 |
| --- | --- | --- |
| `name` | 按权限名称模糊查询 | 否 |
| `code` | 按权限编码模糊查询 | 否 |
| `type` | 按权限类型筛选 | 否 |
| `status` | `1` 启用，`0` 停用 | 否 |
| `pageNum` | 页码 | 否 |
| `pageSize` | 每页条数 | 否 |

返回字段：

| 字段 | 来源 |
| --- | --- |
| `id` | `iam_permission.id` |
| `name` | `iam_permission.permission_name` |
| `code` | `iam_permission.permission_code` |
| `type` | `iam_permission.permission_type` |
| `resourceType` | `iam_permission.resource_type` |
| `actionCode` | `iam_permission.action_code` |
| `moduleCode` | `iam_permission.module_code` |
| `moduleName` | 根据 `moduleCode` 匹配 `iam_permission_module.module_name`，未匹配时回退为 `moduleCode` |
| `status` | `iam_permission.status` 转换为数值 |
| `remark` | `iam_permission.remark` |
| `updateTime` | `iam_permission.updated_at` |

### 权限详情

`GET /admin/permission/{id}`

返回字段与分页列表一致。

### 创建或更新权限

`POST /admin/permission`

`PUT /admin/permission/{id}`

请求示例：

```json
{
  "name": "新增用户",
  "code": "system:user:create",
  "type": "BUTTON",
  "resourceType": "USER",
  "actionCode": "CREATE",
  "moduleCode": "user",
  "status": 1,
  "remark": "新增用户"
}
```

字段引用规则：

| 字段 | 获取或引用方式 |
| --- | --- |
| `moduleCode` | 必须从 `GET /admin/permission-module/options` 的 `value` 获取 |
| `type` | 暂由前端固定选项提供，例如 `NAV_ACCESS`、`MENU`、`BUTTON` |
| `resourceType` | 暂由前端固定选项或页面配置提供，例如 `USER`、`ROLE`、`NAVIGATION` |
| `actionCode` | 暂由前端固定动作选项提供，例如 `VIEW`、`CREATE`、`UPDATE`、`DELETE`、`STATUS`、`ASSIGN` |
| `code` | 前端按权限编码规则填写，后端校验唯一 |

保存校验：

- `moduleCode` 必须存在于权限模块目录。
- `moduleCode` 对应模块必须启用。
- `code` 必须唯一。

## 角色授权接口

### 查询角色授权权限目录

`GET /admin/role/permission/catalog`

返回字段：

| 字段 | 来源 |
| --- | --- |
| `code` | `iam_permission.permission_code` |
| `name` | `iam_permission.permission_name` |
| `type` | `iam_permission.permission_type` |
| `category` | `iam_permission.module_code` |
| `moduleName` | 根据 `category` 匹配 `iam_permission_module.module_name`，未匹配时回退为 `category` |

前端处理：

- 授权提交时只提交权限编码 `permissionCodes`。
- 前端可以直接使用 `moduleName` 展示分组；如需兜底，可用 `GET /admin/permission-module/options` 建立 `value -> label` 映射。

### 分配角色权限

`POST /admin/role/{id}/permissions`

请求示例：

```json
{
  "permissionCodes": [
    "system:user:view",
    "system:user:create"
  ]
}
```

字段来源：

- `permissionCodes` 来自 `GET /admin/role/permission/catalog` 返回项的 `code`。
- 不提交 `moduleCode` 或 `moduleName`。

## 导航授权接口

### 查询导航已分配权限

`GET /admin/navigation/{id}/permissions`

返回字段与角色授权权限项一致：

| 字段 | 来源 |
| --- | --- |
| `code` | `iam_permission.permission_code` |
| `name` | `iam_permission.permission_name` |
| `type` | `iam_permission.permission_type` |
| `category` | `iam_permission.module_code` |
| `moduleName` | 根据 `category` 匹配 `iam_permission_module.module_name`，未匹配时回退为 `category` |

### 分配导航权限

`POST /admin/navigation/{id}/permissions`

请求示例：

```json
{
  "permissionCodes": [
    "system:navigation:view",
    "system:navigation:access:assign"
  ]
}
```

字段来源：

- `permissionCodes` 来自权限目录或权限定义列表中的 `code`。
- 导航不直接引用 `moduleCode`。

## 前端推荐调用顺序

权限定义表单：

1. 调用 `GET /admin/permission-module/options` 获取模块下拉。
2. 用户选择模块后，把选项的 `value` 作为 `moduleCode` 提交。
3. 创建或更新权限时，不提交 `moduleName`。

角色授权页面：

1. 调用 `GET /admin/role/permission/catalog` 获取权限目录。
2. 使用返回项的 `moduleName` 展示模块分组，必要时调用 `GET /admin/permission-module/options` 建立兜底映射。
3. 勾选权限后提交 `permissionCodes`。

导航授权页面：

1. 调用 `GET /admin/navigation/{id}/permissions` 获取已分配权限。
2. 调用权限目录接口或权限列表接口展示可选权限。
3. 提交 `permissionCodes`，不提交模块字段。

## 注意事项

- `moduleCode` 是权限模块目录编码，不是导航编码。
- `moduleName` 只用于展示，不作为保存字段。
- `permissionCode` 是授权关系的核心引用字段，前端分配角色权限和导航权限都提交它。
- 后续如新增 `type`、`resourceType`、`actionCode` 目录表，再把这些字段改为接口下拉来源。
