# 中台管理系统 - 需求规划文档

基于 Vue 3 + Vite + TDesign Vue Next 开发的企业级中台管理系统。

---

## 一、项目概述

### 1.1 项目定位

中台管理系统是企业数字化运营的核心枢纽，整合业务数据、统一管理能力、提供决策支持。系统面向企业内部运营人员，提供数据可视化、业务管理、权限控制等功能。

### 1.2 目标用户

| 用户角色   | 使用场景               | 核心需求           |
| ---------- | ---------------------- | ------------------ |
| 运营人员   | 日常数据监控、业务处理 | 数据看板、快捷操作 |
| 管理人员   | 经营分析、决策支持     | 报表分析、趋势洞察 |
| 系统管理员 | 系统配置、权限管理     | 用户管理、系统设置 |

### 1.3 技术栈

| 技术             | 版本   | 用途       |
| ---------------- | ------ | ---------- |
| Vue              | 3.x    | 前端框架   |
| Vite             | 7.x    | 构建工具   |
| TypeScript       | 5.x    | 类型安全   |
| TDesign Vue Next | 最新版 | UI 组件库  |
| Vue Router       | 5.x    | 路由管理   |
| Pinia            | 3.x    | 状态管理   |
| ECharts          | 6.x    | 数据可视化 |

## 三、功能模块详细设计

### 3.1 数据中枢模块

#### 3.1.1 数据仪表盘（首页）

**功能目标**：提供核心业务数据的一目了然展示，支持快速决策。

**页面结构**：

```
┌─────────────────────────────────────────────────────────────────┐
│  核心指标卡片区（4列布局）                                         │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────┐ │
│  │  总销售额     │ │   总访问      │ │   活跃用户    │ │ 产生订单  │ │
│  │  ¥28,425.00  │ │   ¥768.00    │ │    1,126     │ │   527    │ │
│  │  ↑ 20.5%    │ │   ↑ 20.5%    │ │   ↑ 20.5%    │ │  ↑ 20.5% │ │
│  └──────────────┘ └──────────────┘ └──────────────┘ └──────────┘ │
├──────────────────────────────────────────────┬──────────────────┤
│                                              │                  │
│  统计趋势图（折线图）                          │   销售渠道分布    │
│  - 时间范围选择器                              │   （环形图）      │
│  - 多指标对比                                 │                  │
│  - 数据缩放                                   │   线上 60%       │
│                                              │   线下 40%       │
│                                              │                  │
├──────────────────────────────────────────────┴──────────────────┤
│  业务排名（双栏布局）                                             │
│  ┌─────────────────────────────┐ ┌─────────────────────────────┐ │
│  │      客户销售排名            │ │      供应商订单排名          │ │
│  │  [本周 ▼] [近三月 ▼]        │ │  [本周 ▼] [近三月 ▼]        │ │
│  │  排名  客户名称      订单量   │ │  排名  供应商名称    订单量   │ │
│  │   1   国家电网      7,058   │ │   1   腾讯科技      3,015   │ │
│  │   2   深圳燃气      6,437   │ │   2   大润发        2,015   │ │
│  │   3   国家烟草       ...    │ │   3   海底捞        1,815   │ │
│  │   4   中国电信      3,317   │ │   4   索尼中国      1,015   │ │
│  └─────────────────────────────┘ └─────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

**核心指标说明**：

| 指标     | 说明         | 计算方式         | 更新频率 |
| -------- | ------------ | ---------------- | -------- |
| 总销售额 | 累计成交金额 | 订单实付金额总和 | 实时     |
| 总访问   | 页面访问量   | PV统计           | 实时     |
| 活跃用户 | 独立访客数   | UV统计（去重）   | 实时     |
| 产生订单 | 订单数量     | 订单笔数         | 实时     |

**交互设计**：

| 交互元素 | 触发方式  | 响应动作                        |
| -------- | --------- | ------------------------------- |
| 指标卡片 | 悬停/点击 | 显示详情tooltip，点击跳转详情页 |
| 趋势图   | 选择时间  | 动态刷新图表数据                |
| 排名Tab  | 点击切换  | 切换本周/近三月数据             |
| 表格行   | 点击      | 跳转客户/供应商详情             |

## 七、非功能性需求

### 7.1 性能要求

| 指标       | 目标值   | 说明             |
| ---------- | -------- | ---------------- |
| 首屏加载   | < 2s     | 首页完全加载时间 |
| 路由切换   | < 300ms  | 页面切换响应时间 |
| 接口响应   | < 500ms  | 常规接口响应时间 |
| 大数据列表 | 虚拟滚动 | 超过1000条数据   |
| 图表渲染   | < 1s     | 复杂图表渲染时间 |

### 7.2 兼容性要求

| 浏览器  | 版本        | 支持程度 |
| ------- | ----------- | -------- |
| Chrome  | 最新2个版本 | 完全支持 |
| Edge    | 最新2个版本 | 完全支持 |
| Safari  | 最新2个版本 | 完全支持 |
| Firefox | 最新2个版本 | 完全支持 |

### 7.3 安全要求

- 所有接口需要身份认证（JWT Token）
- 敏感操作需要二次确认
- 密码需要加密存储和传输
- 防止XSS和CSRF攻击
- 操作日志完整记录
