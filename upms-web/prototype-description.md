# 企业级中后台基础平台页面原型说明

## 1. 文档目标

本文档用于说明基础平台各页面的原型结构、交互区域和表单字段，便于产品、设计、前端、后端和测试统一理解页面形态，不涉及高保真视觉稿，仅描述功能原型和页面布局。

## 2. 原型设计原则

- 页面结构统一，降低学习成本
- 列表页优先采用“查询区 + 操作区 + 表格区 + 分页区”结构
- 新增、编辑优先采用弹窗或抽屉形式
- 详情页优先采用抽屉形式
- 操作反馈统一采用成功、失败、确认提示
- 权限不足的按钮不展示

## 3. 全局布局说明

平台采用典型中后台布局：

- 顶部区域：系统名称、全局搜索预留、消息入口、用户头像下拉
- 左侧区域：一级、二级导航
- 主内容区：面包屑、标签页、页面主体
- 底部区域：版权信息，可选

顶部用户下拉菜单建议包含：

- 个人中心
- 修改密码
- 退出登录

## 4. 页面原型说明

### 4.1 登录页

#### 页面结构

- 左侧：品牌宣传区或系统介绍区
- 右侧：登录卡片区

#### 登录卡片内容

- 系统名称
- 登录方式切换 Tab
  - 账号密码登录
  - 手机验证码登录
  - 邮箱验证码登录
- 表单区
- 登录按钮
- 找回密码入口

#### 字段说明

账号密码登录：

- 用户名
- 密码
- 图形验证码

手机验证码登录：

- 手机号
- 手机验证码
- 图形验证码

邮箱验证码登录：

- 邮箱
- 邮箱验证码
- 图形验证码

#### 交互说明

- 支持回车提交
- 验证码支持刷新
- 登录中按钮置灰
- 登录失败显示错误提示
- 三种登录方式统一提交到 `/api/admin/auth/login`，通过 `grantType` 区分登录类型
- 登录成功后返回 `accessToken`，后续请求通过 `Authorization: Bearer {accessToken}` 携带登录态

## 5. 通用交互说明

### 5.1 列表页交互

- 查询区支持查询和重置
- 查询条件变化后支持重新检索
- 表格支持分页
- 删除操作必须二次确认
- 启用、禁用、发布、撤回等状态类操作需确认提示

### 5.2 表单交互

- 必填字段需红色星号标识
- 提交前执行前端校验
- 提交中按钮置灰防重复提交
- 保存成功后关闭弹窗并刷新列表

### 5.3 权限控制

- 无权限的导航不展示
- 无权限的按钮不展示
- 无权限访问页面时跳转 403 页面或显示无权限提示

### 5.4 状态展示

- 启用状态建议使用绿色标签
- 禁用状态建议使用灰色或红色标签
- 发布状态建议使用不同颜色区分未发布、已发布、已撤回

## 7. 结论

本说明文档用于定义页面原型结构和交互边界，重点是保证首期基础平台页面统一、简洁、可实现。后续若进入 UI 设计阶段，可在本原型基础上进一步输出中保真或高保真设计稿。
